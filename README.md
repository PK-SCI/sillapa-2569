## 🚀 ขั้นตอนการติดตั้งและการเชื่อมต่อฐานข้อมูล

### ขั้นตอนที่ 1: ติดตั้ง Google Apps Script บน Google Sheet

1. เปิด Google Sheet ฐานข้อมูล:
   👉 [Google Sheets ID: 1eTcOADESoLJxH19uEpErAfnF_rYJC3ZoTLml9IsViRQ](https://docs.google.com/spreadsheets/d/1eTcOADESoLJxH19uEpErAfnF_rYJC3ZoTLml9IsViRQ/edit)
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ออก แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ [`gas/Code.gs`](gas/Code.gs) ไปวาง
4. (แนะนำ) เลือกฟังก์ชัน `setupInitialSheets` ด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)** เพื่อให้ระบบสร้างหัวตารางและโครงสร้างแผ่นงานให้โดยอัตโนมัติ (หากได้รับแจ้งเรื่องสิทธิ์ ให้กด "ตรวจสอบสิทธิ์" ➔ "ขั้นสูง" ➔ "ไปที่โครงการ")
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน ➔ เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. คลิกไอคอนรูปเฟือง ⚙️ ด้านซ้าย ➔ เลือก **เว็บแอป (Web app)**
   - **คำอธิบาย (Description):** `Sillapa 2026 API`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก)*
7. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
8. คัดลอก **URL ของเว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec`

### ขั้นตอนที่ 2: นำ Web App URL มาใส่ในเว็บไซต์

1. เปิดไฟล์ [`js/config.js`](js/config.js)
2. นำ URL ที่คัดลอกมาวางในช่อง `API_URL`:
   ```javascript
   const CONFIG = {
     API_URL: "https://script.google.com/macros/s/AKfycb.../exec",
     ...
   };
   ```
3. บันทึกไฟล์

---

### ขั้นตอนที่ 3: เผยแพร่เว็บไซต์ขึ้น GitHub Pages (`github.io`)

1. ไปที่เว็บไซต์ [GitHub.com](https://github.com) และเข้าสู่คลังเก็บโค้ด (Repository) ของท่าน
2. นำไฟล์ทั้งหมดในโฟลเดอร์นี้อัปโหลดขึ้น GitHub:
   - `index.html` (อยู่ที่ Root)
   - โฟลเดอร์ `css/`
   - โฟลเดอร์ `js/`
3. ไปที่แท็บ **Settings (การตั้งค่า)** ของ Repository บน GitHub
4. เลื่อนเมนูด้านซ้ายไปที่ **Pages**
5. ในส่วน **Build and deployment** ➔ **Branch**:
   - เลือก Branch: `main` (หรือ `master`)
   - เลือก Folder: `/ (root)`
   - กด **Save**
6. รอประมาณ 1 - 2 นาที GitHub จะสร้าง URL สำหรับเปิดเว็บไซต์ เช่น:
   `https://<username>.github.io/<repository-name>/`

## 🌟 ฟังก์ชันเด่นของระบบ

1. **การออกแบบและสีสัน:**
   - โทนสี ขาว - เหลือง - ส้ม (`#FFFFFF`, `#FFFBEB`, `#F59E0B`, `#EA580C`) สง่างาม ทางการ และทันสมัย
   - โลโก้โครงการ 2 ชิ้น และตั้งค่า Favicon ตามที่ระบุ
   - Responsive Design ใช้งานได้สมบูรณ์แบบทั้งมือถือ แท็บเล็ต โน้ตบุ๊ก และคอมพิวเตอร์
2. **ระบบความปลอดภัยของรหัสผ่าน:**
   - ตรวจสอบความปลอดภัยแบบเรียลไทม์: ตัวเลข + ตัวอักษร + อักขระพิเศษ
   - ระบบกู้คืนรหัสผ่านด้วย เบอร์โทรศัพท์ และ E-mail ที่ตรงกับฐานข้อมูล
3. **การควบคุมโควตาและเงื่อนไขตำแหน่ง:**
   - แต่ละท่านเลือกได้ 1 รายการ
   - ตำแหน่งใดที่มีผู้เลือกแล้วจะถูกปิด **ยกเว้นตำแหน่ง “กรรมการ”** ที่สามารถเลือกได้หลายท่าน
   - เมื่อครบจำนวนที่กำหนด รายการนั้นจะปิดรับสมัครทันทีโดยอัตโนมัติ
4. **การสรุปผลและส่งออกรายงาน:**
   - หน้าหลักแสดงรายชื่อผู้สมัครทุกรายการ พร้อมระบบค้นหาแบบทันที
   - ปุ่มส่งออกเป็นไฟล์ **Excel (.xlsx)** พร้อมจัดคอลัมน์
   - ปุ่มส่งออกเป็น **PDF / พิมพ์รายงานทางการ**
