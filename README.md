# ระบบแต่งตั้งคณะกรรมการดำเนินงานศิลปหัตกรรมนักเรียน ปีการศึกษา 2569

เว็บไซต์ลงทะเบียน / เข้าสู่ระบบ / สมัครเป็นคณะกรรมการการตัดสินผลการแข่งขัน
**ระดับสำนักงานเขตพื้นที่การศึกษา สำนักงานเขตพื้นที่การศึกษามัธยมศึกษาชัยภูมิ**
ศูนย์พัฒนาวิชาการวิทยาศาสตร์และเทคโนโลยี โรงเรียนภูเขียว อำเภอภูเขียว จังหวัดชัยภูมิ

- **โฮสต์หน้าเว็บ:** GitHub Pages (ไฟล์สถิตทั้งหมด)
- **ฐานข้อมูล:** Google Sheets ผ่าน Google Apps Script (Web App)

## ขั้นตอนที่ 2 — ติดตั้ง Google Apps Script

1. เปิด Google Sheet ฐานข้อมูล → เมนู **Extensions (ส่วนขยาย) > Apps Script**
2. ลบโค้ดตัวอย่างออก แล้ว **วางโค้ดทั้งหมดจากไฟล์ `appsscript/Code.gs`**
3. ตรวจสอบบรรทัด `SPREADSHEET_ID` ให้ตรงกับ ID ของ Sheet ของท่าน
   (เปิดตัวเลือกตั้งค่าเพิ่มเติมได้ในตอนต้นไฟล์ เช่น อนุญาตให้สมัครหลายรายการ)
4. กด **Deploy > New deployment**
   - เลือกประเภท **Web app**
   - **Execute as:** Me
   - **Who has access:** **Anyone**
   - กด Deploy และอนุญาตสิทธิ์ (Authorize) ให้ครบ
5. **คัดลอก Web app URL** ที่ลงท้ายด้วย `/exec`

> ทุกครั้งที่แก้ไขโค้ด Code.gs อย่าลืมกด **Deploy > Manage deployments > ดินสอ (แก้ไข) > Version: New version > Deploy** ไม่เช่นนั้นการแก้ไขจะไม่มีผล

## ขั้นตอนที่ 3 — เชื่อมเว็บไซต์กับ Apps Script

เปิดไฟล์ **`js/config.js`** แล้ววาง URL ที่ได้:

```js
window.SILLAPA_CONFIG = {
  APPS_SCRIPT_URL: "https://script.google.com/macros/s/ใส่รหัสของท่าน/exec",
  ALLOW_MULTIPLE_EVENTS: false
};
```

> ถ้ายังไม่ใส่ URL เว็บจะทำงานใน "โหมดตัวอย่าง" ด้วยข้อมูลจำลอง เพื่อให้ทดสอบหน้าเว็บได้ก่อน
> บัญชีทดสอบในโหมดตัวอย่าง: เบอร์ `0812345678` รหัสผ่าน `Pass@123`

## ขั้นตอนที่ 4 — เผยแพร่ด้วย GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `sillapa-committee`)
2. อัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ (`index.html`, `css/`, `js/`)
3. ไปที่ **Settings > Pages**
   - **Source:** Deploy from a branch
   - **Branch:** `main` / โฟลเดอร์ `/ (root)` > Save
4. รอสักครู่ แล้วเข้าเว็บไซต์ที่ `https://ชื่อผู้ใช้.github.io/sillapa-committee/`

## การใช้งานระบบ

| หน้า | รายละเอียด |
|---|---|
| **เข้าสู่ระบบ** | กรอกเบอร์โทร 10 หลัก (ตรวจกับแผ่นงาน `admin` คอลัมน์ A) และรหัสผ่าน (คอลัมน์ B) |
| **ลงทะเบียน** | กรอกคำนำหน้า ชื่อ ชื่อกลาง สกุล (ตัวหนังสือเท่านั้น) โรงเรียน เบอร์โทร E-mail ตำแหน่ง วิทยฐานะ สาขาวิชา และตั้งรหัสผ่าน (ต้องมีตัวเลข ตัวอักษร อักขระพิเศษ อย่างละ 1 ตัว ยืนยันรหัสให้ตรงกัน) — ระบบบันทึกชื่อเต็มอัตโนมัติ |
| **ลืมรหัสผ่าน** | กรอกเบอร์โทร + E-mail ที่ตรงกับตอนลงทะเบียน ระบบจะส่งรหัสผ่านไปที่อีเมล และแสดงบนจอ |
| **หน้าหลัก** | แสดงรายการแข่งขันทั้งหมด พร้อมวันที่ สถานที่ จำนวนที่รับ และแถบแสดงความเต็ม — รายการที่สมัครครบจะ **ปิดรับทันที** |
| **หน้ารายการ** | แสดงผู้สมัครทั้งหมดของรายการ และให้เลือกตำแหน่ง — ตำแหน่งที่มีคนเลือกแล้วจะเลือกไม่ได้อีก **ยกเว้น "กรรมการ"** ที่รับได้หลายท่าน เมื่อกดยืนยันระบบบันทึกวันที่-เวลาลงแผ่นงาน `save` |
| **รายชื่อผู้สมัคร** | ดูรายชื่อ-สกุล สาขาวิชา ตำแหน่งที่สมัคร โรงเรียน แยกตามรายการ พร้อมปุ่ม **ส่งออก Excel (.xlsx)** และ **ส่งออก PDF** (เปิดหน้าต่างพิมพ์ ให้เลือก "บันทึกเป็น PDF") |

## การปรับแต่งเพิ่มเติม

- **เปลี่ยนสี:** แก้ตัวแปรในตอนต้นไฟล์ `css/style.css` (โซน Design Tokens)
- **อนุญาตให้สมัครหลายรายการ:** เปลี่ยน `ALLOW_MULTIPLE_EVENTS` เป็น `true` ในทั้ง `js/config.js` และ `appsscript/Code.gs`
- **โลโก้:** โลโก้ทั้งสองตัวดึงจาก Google Drive อยู่ในแท็ก `<img>` ของ `index.html` หากต้องการเปลี่ยน ให้เปลี่ยน URL เป็น `https://lh3.googleusercontent.com/d/ไฟล์ID`
- **ข้อความท้ายเว็บ:** แก้ในแท็ก `<footer>` ของ `index.html` (ปัจจุบัน: © SILLAPA CHAIYAPHUM 2026 ALL RIGHTS RESERVED)
- **ห้ามแสดงรหัสผ่านบนจอตอนลืมรหัส:** ตั้ง `SHOW_PASSWORD_ON_FORGOT = false` ใน `Code.gs` (ระบบจะส่งทางอีเมลเท่านั้น)

## หมายเหตุด้านความปลอดภัย

- รหัสผ่านเก็บแบบข้อความธรรมดาใน Google Sheet ตามโครงสร้างที่กำหนด เพราะผู้ดูแลต้องเห็น/แก้ไขได้จาก Sheet โดยตรง — ควรจำกัดสิทธิ์การเข้าถึง Spreadsheet เฉพาะผู้ดูแลระบบเท่านั้น
- Apps Script ต้อง Deploy แบบ **Anyone** เพื่อให้หน้าเว็บจาก GitHub Pages เรียกใช้ได้ แต่ตัว Sheet เองไม่ควรแชร์แบบสาธารณะ
